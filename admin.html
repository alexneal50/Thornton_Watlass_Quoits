Publishing your changes

  1. Click Download updated data.json above.
  2. Go to your website's repository on GitHub.com and open the existing data.json file.
  3. Click the pencil (edit) icon, delete the contents, and paste in the downloaded file's contents — or use "Upload files" and drag the new data.json in to replace it.
  4. Click Commit changes. The live site updates automatically within a minute or two.

See the README in the project files for full GitHub Pages setup steps.
