Publishing your changes

  1. Click Download updated data.json above, or use Copy to clipboard in the "Copy data.json" box if Download doesn't work on your device.
  2. Go to your website's repository on GitHub.com and open the existing data.json file.
  3. Click the pencil (edit) icon, select all and delete, then paste in what you downloaded or copied — or, if you downloaded a file, use "Upload files" and drag it in to replace data.json.
  4. Click Commit changes. The live site updates automatically within a minute or two.

See the README in the project files for full GitHub Pages setup steps.
